CMPS 4883 – Programming Techniques is a course at Midwestern State University (MSU Texas), with this project authored by **Alexander Dela Cruz**. The assignments consist of C++ solutions to competitive programming problems sourced from [LeetCode](https://leetcode.com) and the [UVA Online Judge](https://onlinejudge.org), progressing from foundational algorithm design to more advanced data structures and graph traversal.

## Assignments

| Assignment | Name | Topics Covered |
|:---:|---|---|
| **A05** | [Easy Breezy](/prog-tech/easy-problems) | Basic algorithms — integer math, string manipulation, greedy reachability, binary search, hash sets |
| **A06** | [Hardwood Sneezy](/prog-tech/map-sorting) | Map-based frequency counting and custom sort comparators |
| **A07** | Priority Queezy | Priority queues *(no code submitted)* |
| **A08** | [Graphin Sleezy](/prog-tech/graph-traversal) | Graph traversal — DFS on 2D grids, flood fill, and connected components |

## Technologies

All solutions are written in **C++** and make use of the C++ Standard Template Library (STL):

- **`std::map`** — ordered key–value storage used for word frequency counting
- **`std::stack`** — explicit stack for iterative depth-first search
- **`std::vector`** — dynamic arrays used throughout for grids, pairs, and character buffers
- **`std::unordered_set`** *(task spec)* / **`std::sort`** — used for sequence detection
