Welcome to **UselessFuru**, a code portfolio by Alexander Dela Cruz. Here you'll find four projects spanning GPU parallel computing with CUDA, relational database design with MySQL, competitive programming solutions in C++, and a real-time terminal-based dictionary search tool. Each project is documented with context, implementation details, and technical breakdowns to help you understand both the what and the why.
